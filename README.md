# Brandon Lim - Developer Portfolio

A personal portfolio showcasing my engineering projects, design experience, and journey as I prepare for university admissions. Built to be fast, interactive, and visually striking, this portfolio reflects my capabilities in full-stack development and UI/UX design.

## 🎯 Purpose
The main goal of this project is to provide a comprehensive, interactive resume. It goes beyond a simple PDF by demonstrating technical skills through live code—featuring custom scroll animations, interactive physics components, and a custom dark mode UI system.

## 🛠️ Tech Stack & Framework
- **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
- **Library:** [React 19](https://react.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Language:** TypeScript
- **Animations:** [Framer Motion](https://www.framer.com/motion/) & [GSAP](https://gsap.com/) (ScrollTrigger)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Components:** Custom UI inspired by [shadcn/ui](https://ui.shadcn.com/)

## 🚀 Build Instructions

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/Brandonnnlc/Brandon-Lim-s-Portfolio-.git
   cd Brandon-Lim-s-Portfolio-
   ```

2. Install the necessary dependencies:
   ```bash
   npm install
   ```

3. Run the local development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the portfolio live.

### Production Build
To create an optimized production build:
```bash
npm run build
npm run start
```

## 📂 Key Features
- **Dynamic Projects Showcase:** Comprehensive case studies of projects ranging from AI SaaS platforms to personal finance apps.
- **Scroll-driven Animations:** GSAP timelines dictating element reveals based on scroll positions.
- **Interactive UI Elements:** Hover cards, draggable components, and custom Framer Motion accordions.
- **Responsive Design:** Fully optimized layouts across mobile, tablet, and desktop viewports.
